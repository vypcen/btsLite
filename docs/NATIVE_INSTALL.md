# Установка BlackCat Testing Community из EXE или DEB

Community поддерживает до пяти активных пользователей. Администраторы, тестировщики, разработчики и наблюдатели занимают по одному месту. На компьютер каждого участника приложение устанавливать не требуется: команда открывает один сервер в браузере.

## Windows x64

1. Скачайте `BlackCat-Testing-Community-*-win-x64-Setup.exe` и запустите его с правами администратора.
2. Установщик создаст службы `BlackCatTestingCommunityDb` и `BlackCatTestingCommunity`. Откройте **BlackCat Testing Community** в меню «Пуск» или перейдите на `http://localhost:3002`.
3. Код для создания первого администратора находится в файле `%ProgramData%\BlackCatTestingCommunity\app.env` в строке `SETUP_CODE`. Откройте файл с правами администратора. После входа приложение покажет лицензионное соглашение.
4. Если приложение не запускается, откройте **Службы Windows** и проверьте обе службы. Журналы приложения находятся в `%ProgramData%\BlackCatTestingCommunity\logs`.

Приложение использует порт 3002 и собственную базу PostgreSQL на `127.0.0.1:55432`. Для переустановки запустите новый установщик. База, настройки, вложения и резервные копии лежат в `%ProgramData%\BlackCatTestingCommunity` и сохраняются при переустановке и удалении приложения.

## Ubuntu 24.04 x86-64

Скачайте DEB-пакет и установите его на компьютере или сервере Ubuntu с доступом к пакетному репозиторию ОС:

```sh
sudo apt install ./blackcat-testing-community_2.0.0_amd64.deb
sudo grep '^SETUP_CODE=' /etc/blackcat-community/app.env
```

Откройте `http://localhost:3002` и создайте администратора с кодом установки. После входа приложение покажет лицензионное соглашение. Службы запускаются автоматически. Для диагностики используйте:

```sh
sudo systemctl status blackcat-community blackcat-community-db
sudo journalctl -u blackcat-community -u blackcat-community-db
```

Пакет использует PostgreSQL 16 из репозитория Ubuntu и запускает отдельный экземпляр через локальный Unix-сокет. Конфигурация хранится в `/etc/blackcat-community`, база и файлы — в `/var/lib/blackcat-community`. Повторная установка сохраняет эти каталоги. Удаление пакета останавливает службы и сохраняет данные.

## Доступ команды и обновление

Первая установка доступна только с хоста. Для доступа команды настройте HTTPS-прокси перед портом 3002. Оставьте базу доступной только приложению. Для переезда на новую машину сохраните резервную копию, вложения и `APP_SECRET` из конфигурации.

Перед обновлением с редакции, где просмотровые аккаунты шли отдельно, заблокируйте лишние записи в старой версии. Новый сервер запускается при наличии не более пяти активных пользователей. Перед обновлением создайте резервную копию.
